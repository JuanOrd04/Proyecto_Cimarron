Operador
Descripción 
Ejemplo de Uso

Mayor o igual que

Menor o igual que

Al realizar una operación relacional en C, la respuesta a dicha operación puede ser un 0 ó 1. 
0: también conocida como falso, indica que la condición no se cumplió.

1: también conocida como verdadero, indica que la condición se cumplió.
Estos valores reciben el nombre de Valores Booleanos.

Los Operadores Lógicos son utilizados para unir dos condiciones 

11

Operadores Lógicos
Operador
Descripción 
Ejemplo de Uso
&&
Regresa verdadero si ambas condiciones se cumplen
x < 4 && x >2
Si x es menor a 4  Y mayor a 2
||
Regresa verdadero si una o ambas condiciones se cumplen
x < 4 || x < 3
Si x es menor a 4 O es menor a 3
!
Invierte el resultado de la condición
! ( x < 4) 
Si x NO es menor a 4
