Otro tipo de estructura de control de iteración es el ciclo while, el cual realiza un bloque de código mientras se cumpla una condición específica. 
while (condición) {
//Bloque de código
}

Ciclo do-while

El ciclo do-while es una variante del ciclo while, cuya principal diferencia radica en el hecho de que la comprobación de iteración se produce después de haber ejecutado al menos una vez el contenido del bloque de instrucciones.


10
Ciclo do-while
Concepto

La comprobación de iteración se realiza después de haber ejecutado al menos una vez el bloque de código y se repetirá siempre y cuando la condición sea verdadera:


11
Ciclo do-while
Flujo de Operación 
Condición
V
Ejecutar bloque de código
F

do {
//Bloque de código
condición = nuevo_valor;
} while (condición)

Esta sintaxis garantiza que el ciclo será ejecutado al menos una vez, aunque la condición sea falsa.

12
Ciclo do-while
Sintaxis
No olviden agregar una cláusula de actualización para la condición al final del bloque.

Ciclo While

Resumen de Diferencias
Ciclo While
Ciclo Do-While

El bloque de código es ejecutado antes de evaluar la condición.
El bloque de código solo se ejecuta si se cumple la condición, y termina una vez que esta es falsa.
El bloque de código se ejecuta al menos una vez, sin importar si la condición se cumple o no.
